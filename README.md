# tic-tac-web-scocket

## Tecnologias utilizadas no backend
- Springboot (4.1.2)
- Java JDK 21
- Banco de dados H2
- Websocket (STOMP)

## Tecnologias utilizadas no backend
- HTML + CSS + Javascript

## Telas
- Homepage
- Teste de conexão
- Dashboard
- Jogo

## Features por tela
### Homepage
- Cadastro de usuário
- Login de usuário

### Teste de conexão
- Conectar ao servidor
- Desconectar
- Enviar mensagem
- Exibir mensagem

### Dashboard
- Mostrar usuário logado (cabeçalho)
- Deslogar da tela (botão do cabeçalho)
- Mostrar lista de jogadores ativos
